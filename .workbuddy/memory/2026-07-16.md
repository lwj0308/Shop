# 2026-07-16

## 修复 shared 包 import.meta.env 类型报错
- 现象：`packages/shared/src/api/request.ts` 中 `import.meta.env` 报"类型 ImportMeta 上不存在属性 env"。
- 根因：`packages/shared` 包无 tsconfig.json 且无 Vite 类型声明；各 web-* 应用 tsconfig 只 include 自己的 src，未涵盖 shared/src，导致 tsserver 单独解析 shared 源码时落入无 vite/client 类型的推断项目。
- 修复：
  1. 新增 `packages/shared/src/env.d.ts`（/// <reference types="vite/client" /> + ImportMetaEnv/ImportMeta 声明）。
  2. 新增 `packages/shared/tsconfig.json`（extends ../../tsconfig.base.json，types: ["vite/client"]，include src）。
- 验证：`tsc -p packages/shared/tsconfig.json --noEmit` 退出码 0。
- 约定：前端为 npm workspaces monorepo（packages: shared/web-user/web-merchant/web-admin），Vite 环境变量类型统一在各包 env.d.ts 声明。
